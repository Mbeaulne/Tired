# Game notes

## Long-term vision

Tired is an open-source game whose long-term goal is a persistent open world
that keeps growing. People can contribute their own code, art, and world
content to expand the game over time.

The official project is curated by [Mbeaulne](https://github.com/Mbeaulne).
Contributions arrive through pull requests, and only Mbeaulne merges them into
the official `main` branch. Anyone can fork and share the project under its
[MIT license](LICENSE).

## How we get there

Development stays a daily warm-up: choose one small, inspectable change at a
time. A broad idea starts a conversation and a plan; it does not authorize a
whole feature. These rules apply to community contributions too. See
[AGENTS.md](AGENTS.md) and [CONTRIBUTING.md](CONTRIBUTING.md).

The current prototype has an endless repeating floor, a stationary player,
and decorative depth markers. Persistence, unique world content, and movement
are future work. The persistence model, online play, storage, hosting, and
how accepted content reaches a running world remain undecided. Select and
plan those changes separately when they become the next experiment.

This note records the direction, rather than an implementation roadmap.
